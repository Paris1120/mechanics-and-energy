# Physics Simulation - 물리 기반 궤도 계산기

> 역학과 에너지 수행평가 프로젝트
> 밀양고등학교 2학년

목표 지점까지의 거리, 높이, 사람의 키, 물체의 질량 등을 입력하면 **포물선 운동 공식**과 **수치해석**으로 필요한 발사 조건(초기 속도, 발사 각도, 도달 시간, 필요한 힘)을 계산하고, 궤적을 애니메이션과 그래프로 시각화하는 웹 애플리케이션입니다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로그램명 | 물리 기반 궤도 계산기 (Physics Simulation) |
| 과목 | 역학과 에너지 |
| 연계 단원 | 포물선 운동, 운동 방정식, 운동 에너지와 위치 에너지, 역학적 에너지 보존, 일-에너지 정리, 충격량 |
| 형태 | 웹사이트 (서버 없이 브라우저에서 동작) |
| 지원 기기 | PC, 태블릿, 휴대폰 (세로/가로) |

### 제작 동기

"농구공을 골대에 넣으려면 얼마나 세게, 몇 도로 던져야 할까?"라는 질문에서 시작했습니다. 교과서의 포물선 운동 공식은 보통 **속도와 각도를 주고 거리를 구하는** 방향이지만, 이 프로그램은 반대로 **목표 지점을 주고 필요한 발사 조건을 구합니다.** 또한 실제 상황에 가깝게 공기저항까지 고려합니다.

### 핵심 메시지

> 공기저항이 없으면 **질량은 궤적에 영향을 주지 않는다.**
> 하지만 질량은 **필요한 힘, 에너지, 충격량**에 비례해서 영향을 준다.

## 2. 주요 기능

### 계산

- **3가지 계산 모드**
  - 최소 힘 모드: 가장 작은 초기 속도로 도달하는 최적 각도를 자동 계산
  - 각도 고정 모드: 입력한 각도로 던질 때 필요한 초기 속도 계산
  - 속도 고정 모드: 입력한 속도로 던질 때 가능한 발사 각도(최대 2개) 계산
- **공기저항 ON/OFF**: RK4 수치해석으로 공기저항이 있는 궤적 계산
- **중력 가속도 선택**: 지구, 달, 화성, 목성, 직접 입력
- **물체 프리셋**: 야구공, 테니스공, 농구공, 축구공, 투포환, 탁구공

### 시각화

- 궤적 애니메이션 (재생, 일시정지, 타임라인 이동, 재생 속도 0.25x ~ 2x)
- 속도 벡터 표시 (v, vx, vy)
- 공기저항 없을 때의 궤적, 다른 가능 각도의 궤적 비교 표시
- 최고점, 발사 각도, 목표 지점 표시
- 실시간 위치(X, Y)와 속력 표시

### 그래프

- 높이-시간 그래프
- 속도-시간 그래프 (vx, vy, 속력)
- 에너지-시간 그래프 (운동 에너지, 위치 에너지, 역학적 에너지)
- 궤적(x-y) 그래프

### 수식

- 애니메이션 시간에 맞춰 공식에 실제 값이 대입되는 실시간 수식
- 1단계부터 11단계까지 값을 대입한 단계별 풀이 페이지

## 4. 사용 방법

1. 왼쪽 메뉴에서 **궤도 계산기**를 선택합니다.
2. 오른쪽 입력창(휴대폰은 하단의 **입력** 탭)에 조건을 입력합니다.
3. **계산하기** 버튼을 누릅니다.
4. 중앙 화면에서 궤적 애니메이션이 재생되고, 하단 패널에 결과가 표시됩니다.
5. 하단 패널의 **결과 / 그래프 / 수식** 탭으로 원하는 정보를 확인합니다.
6. 더 자세한 내용은 왼쪽 메뉴의 **계산 결과, 그래프, 수식 풀이** 페이지에서 볼 수 있습니다.

### 메뉴 구성

| 메뉴 | 내용 |
|---|---|
| 궤도 계산기 | 입력, 시뮬레이션, 결과, 그래프, 수식을 한 화면에서 확인 |
| 계산 결과 | 결과 카드 전체와 입력 조건 요약표 |
| 그래프 | 4개의 그래프를 한 화면에 크게 표시 |
| 수식 풀이 | 실제 값을 대입한 단계별 풀이 |
| 이론 | 사용한 물리 공식과 원리 설명 |
| 팀 소개 | 팀원과 역할 |

## 5. 입력값과 출력값

### 입력값

| 분류 | 항목 | 단위 | 설명 |
|---|---|---|---|
| 위치/환경 | 목표 수평 거리 | m | 발사 지점부터 목표까지의 수평 거리 |
| | 목표 지점 높이 | m | 예: 바닥 0, 농구 골대 3.05 |
| | 발사 지면 높이 | m | 언덕이나 건물 위에서 던지는 경우 |
| | 중력 가속도 | m/s² | 지구, 달, 화성, 목성, 직접 입력 |
| 사람 | 키 | m | 발사 높이 계산에 사용 |
| | 팔 가속 거리 | m | 던질 때 손이 물체를 밀어주는 거리 |
| 물체 | 물체 종류 | - | 선택하면 질량, 지름, 항력계수 자동 입력 |
| | 질량 | kg | 힘, 에너지, 공기저항 계산에 사용 |
| | 지름 | m | 공기저항 단면적 계산에 사용 |
| | 항력계수 | - | 물체 모양에 따른 공기저항 계수 |
| 계산 모드 | 모드 | - | 최소 힘 / 각도 고정 / 속도 고정 |
| | 발사 각도 | ° | 각도 고정 모드에서 사용 |
| | 초기 속도 | m/s | 속도 고정 모드에서 사용 |
| 공기저항 | 공기저항 고려 | - | ON/OFF |
| | 공기 밀도 | kg/m³ | 기본값 1.225 (해수면, 15°C) |

### 물체 프리셋

| 물체 | 질량 (kg) | 지름 (m) | 항력계수 |
|---|---|---|---|
| 야구공 | 0.145 | 0.074 | 0.35 |
| 테니스공 | 0.058 | 0.067 | 0.55 |
| 농구공 | 0.62 | 0.24 | 0.47 |
| 축구공 | 0.43 | 0.22 | 0.25 |
| 투포환 | 7.26 | 0.12 | 0.47 |
| 탁구공 | 0.0027 | 0.04 | 0.50 |

### 출력값

| 항목 | 단위 | 설명 |
|---|---|---|
| 필요한 초기 속도 | m/s, km/h | 목표에 도달하기 위한 발사 속도 |
| 발사 각도 | ° | 계산된 각도와 같은 속도로 가능한 다른 각도 |
| 예상 도달 시간 | s | 발사부터 목표 도달까지 걸리는 시간 |
| 최고점 높이 | m | 궤적의 가장 높은 지점과 그 위치 |
| 목표 도달 속도 | m/s | 목표 지점에 도달할 때의 속력과 각도 |
| 필요한 평균 힘 | N | 일-에너지 정리로 계산, kg 단위로도 환산 |
| 발사 운동 에너지 | J | 발사 순간의 운동 에너지와 충격량 |
| 역학적 에너지 | J | 공기저항 OFF일 때 보존되는 값 |
| 공기저항 에너지 손실 | J, % | 공기저항 ON일 때 손실된 에너지 |
| 공기저항 없을 때 필요 속도 | m/s | 공기저항의 효과 비교 |

## 7. 프로그램의 가정과 한계

### 가정

- 발사 높이는 지면 높이에 키의 0.9배를 더한 값으로 가정
- 물체는 회전하지 않는 구 (마그누스 효과 무시)
- 중력 가속도는 일정하고, 지구의 곡률과 자전은 무시
- 공기 밀도와 항력계수는 일정
- 평균 힘을 계산할 때 던지는 동안 중력이 하는 일은 무시
- 바람은 고려하지 않음

### 한계

- 실제 투구에서는 공의 회전 때문에 궤적이 휘어질 수 있음
- 항력계수는 실제로 속도에 따라 조금씩 달라짐
- 사람이 실제로 낼 수 있는 힘의 한계는 반영하지 않음
- 수치해석 특성상 아주 작은 오차가 발생할 수 있음

## 8. 파일 구조

```
physics-simulation/
├── index.html          화면 구조 (메뉴, 계산기, 결과, 그래프, 수식 풀이, 이론, 팀 소개)
├── css/
│   └── style.css       다크 테마 디자인, 반응형 레이아웃
├── js/
│   ├── physics.js      물리 엔진 (공식, RK4 수치해석, 발사 조건 탐색)
│   ├── renderer.js     캔버스 그리기 (궤적, 사람, 목표, 벡터)
│   ├── charts.js       그래프 (높이, 속도, 에너지, 궤적)
│   └── main.js         화면 전환, 입력 처리, 애니메이션, 결과 출력
└── README.md           프로젝트 설명서
```

### 각 파일의 주요 함수

| 파일 | 함수 | 역할 |
|---|---|---|
| physics.js | `solve()` | 입력을 받아 모든 결과를 계산하는 메인 함수 |
| | `idealMinSpeed()` | 최소 속도 공식 계산 |
| | `idealSpeedForAngle()` | 각도로부터 필요한 속도 계산 |
| | `idealAnglesForSpeed()` | 속도로부터 가능한 각도 계산 |
| | `rk4Step()` | RK4 한 단계 계산 |
| | `simulate()` | 공기저항 포함 궤적 시뮬레이션 |
| | `speedForAngle()`, `minSpeed()` | 공기저항이 있을 때 발사 조건 탐색 |
| renderer.js | `draw()` | 시뮬레이션 화면 전체 그리기 |
| | `fitView()` | 화면 크기에 맞게 축척 자동 계산 |
| charts.js | `create()` | 그래프 생성 |
| | `setData()`, `setCursor()` | 데이터 갱신, 현재 시간 표시 |
| main.js | `readInput()` | 입력값 읽기와 오류 검사 |
| | `applyLayout()` | 화면 크기에 따라 레이아웃 전환 |
| | `play()`, `redraw()` | 애니메이션 재생과 화면 갱신 |
| | `renderSolution()` | 단계별 수식 풀이 생성 |

## 10. 화면 크기별 지원

페이지 전체는 스크롤되지 않고, 화면 높이에 맞게 자동으로 배치됩니다.

| 화면 | 너비 | 레이아웃 |
|---|---|---|
| 큰 모니터 | 1600px 이상 | 입력창과 하단 패널이 더 넓어짐 |
| PC | 1200px 이상 | 왼쪽 메뉴 + 시뮬레이션 + 하단 패널 + 오른쪽 입력창 |
| 태블릿, 작은 노트북 | 768 ~ 1199px | 왼쪽 메뉴가 아이콘만 있는 얇은 바로 변경 |
| 휴대폰 세로 | 767px 이하 | 메뉴가 하단 탭바로 이동, 입력창은 하단 패널의 입력 탭으로 이동 |
| 휴대폰 가로 | 높이 560px 이하 | 시뮬레이션과 하단 패널이 좌우로 배치 |
